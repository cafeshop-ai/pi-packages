## 通过的边界

1. 加载、status、暂停后的重载均不自动连接；恢复必须显式执行。配置路径含空格可用。
2. 恢复沿用真实宿主持久回执和手动 consumed 检查点；已处理消息不重投，新消息继续投递。不确定投递不能绕过原生 retry/skip 确认。
3. 地址、房间、成员、token 变化时在联网前拒绝；文件丢失或原有读取校验失败时不使用缓存凭据、不查找备用配置。明确 connect 才能替换绑定。
4. 只读取当前分支且会话 ID 匹配的最新本地 custom entry；新会话/分叉不继承；房间 custom_message 不能创建绑定；坏的最新记录不回退旧记录。
5. 重复 resume 不重建活跃监听；暂停或会话切换后，旧异步连接结果不能重启监听，旧失败也不能暂停更新的连接。绑定写入失败不启动监听。

原生检查逐次确认模型请求没有成员 token 或绑定路径；会话文件没有成员 token。路径仍存在本地 custom 元数据中，JSONL 导出须脱敏。

## 尚未验收 / 保留限制

- 普通运行中的 Pi 还需用户手动 /reload；旧版未保存路径，首次迁移须在新版用原配置 connect 一次。没有替用户远程 reload、重启或改写会话 JSONL。
- 命令在收到它的 Pi 实例内执行，不扫描网关宿主；没有新增跨进程互斥租约。同一成员凭据仍不应在多个进程同时监听。
- Windows 沿用原有文件身份/读取校验，不自动审计或配置 NTFS ACL；私有目录 ACL 仍是已有前置条件。本轮不等于 Windows 通用客户端 ACL 支持完成。
- 未做真实模型、生产房间、新发布包、操作系统重启或长期断线验收。
