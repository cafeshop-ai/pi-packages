# Agent Adapter 边界

- ACP 优先，原生接入只用于已证明的能力缺口；不为每个 ACP 品牌复制 adapter。
- 新建/连接已有是会话来源，不是两套消息实现。会话所有权不等于后台进程所有权。
- 保留后端原生 session ID；历史恢复不等于共享活动执行。未知状态不得自动重发。
- 网关统一认证、授权与控制权；adapter 映射能力、消息、审批、状态。Room Goal 仍由指定人类审核。
- 实验默认零模型请求，live 必须显式开启、设置硬 prompt 预算、拒绝工具审批并使用临时工作目录。
- 不读取或复制凭据，不导出用户会话历史，不更改全局模型与登录配置；不自动部署或重启 Pi。
